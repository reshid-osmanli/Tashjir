# نظام الحركة — ANIMATION SYSTEM

> مشروع التشجير · الحركة تشرح النظام، لا تُزيّنه.
> التنفيذ المرجعي: طبقة «الحركة» في `src/app/globals.css` + `src/components/motion/`.

---

## 1. قاعدة القرار (§207)

```text
يكفي CSS؟            ⇒ CSS. لا حالة React، لا مكتبة.
يكفي SVG؟            ⇒ SVG. لا Canvas، ولا WebGL.
يكفي IntersectionObserver للتوقيت؟ ⇒ لا GSAP.
لا حاجة إلى حركة؟    ⇒ لا تُضف شيئا.
```

**الحالة الراهنة للمشروع:** لا تُضاف أي مكتبة حركة. الرئيسية والمحرر والمصحف
تحقق كل ما تحتاجه بـ CSS (انتقالات، `@keyframes`، `stroke-dashoffset`) + مراقب
تقاطع واحد مشترك للظهور عند التمرير. هذا يحقق §81 و§153 و§205–207 بلا تكلفة تحميل.

يُسمح بإضافة GSAP لاحقا في **الرئيسية وحدها** إن ظهرت حاجة فعلية إلى تسلسل تمرير
معقّد، بشرط: تحميل مؤجّل، وعدم دخوله إلى مسار المحرر/المصحف (§153، §80).

## 2. وسائط الحركة (Motion Tokens)

| التوكن | القيمة | المجال |
|---|---|---|
| `--motion-micro` | `120ms` | تغذية راجعة فورية: زر، خلية حرف، صف قائمة |
| `--motion-fast` | `160ms` | توجيه، تغيير حالة، تبديل تبويب |
| `--motion-normal` | `240ms` | ظهور عنصر، انتقال واجهة، درج |
| `--motion-panel` | `300ms` | تبديل محتوى لوحة الخصائص |
| `--motion-diagram` | `560ms` | رسم خط، ظهور عقدة، ظهور قسم |
| `--motion-hero` | `820ms` | المشهد الافتتاحي (يُنفَّذ على خطوات لا مرة واحدة) |

التسهيلات:

| التوكن | المنحنى | الاستخدام |
|---|---|---|
| `--ease-standard` | `cubic-bezier(.2,.7,.3,1)` | الافتراضي لكل تفاعل |
| `--ease-out-quiet` | `cubic-bezier(.16,1,.3,1)` | ظهور هادئ ينتهي بثبات |
| `--ease-in-out-quiet` | `cubic-bezier(.4,0,.2,1)` | تبديلات متناظرة |
| `--ease-draw` | `cubic-bezier(.62,.02,.34,1)` | ترسيم المسارات |

لا منحنيات مرتدّة (`bounce`, `elastic`) في أي مكان: لا تلائم مخططا علميا (§29).
لا حركة أبدية (infinite) إلا مؤشر انتظار حقيقي.

## 3. كثافة الحركة لكل سطح

| السطح | الكثافة (§136–140) | ما يُسمح | ما يُمنع |
|---|---|---|---|
| الرئيسية | عالية في الـ Hero، متوسطة في الشرح، منخفضة في التفاصيل العلمية، صفر في التذييل | ترسيم، ظهور متتالٍ، عدّ مرة واحدة، تمرير سردي | حلقة أبدية، parallax ثقيل، حركة عند كل hover على كل سطر |
| المحرر | منخفضة، دلالية | تسليط، نبضة إحضار، تغذية راجعة للتحديد، ترسيم عند إنشاء خط فقط | حركة زخرفية، إعادة تشغيل الترسم عند كل تصيير |
| المصحف | شبه معدومة | تمرير ناعم، بروز خفيف، نبضة تركيز هادئة | parallax، ظهور آية بآية، أي إزاحة للنص |
| التتبع | متوسطة | خط زمني يتحرك عند الاختيار، كشف «قبل/بعد»، ظهور صفوف | حركة تبدّل ترتيب الصفوف |
| الإدارة | منخفضة | انتقالات جدول وحالة | رسوم متحركة |

## 4. الأنماط المعيارية

### 4.1 الظهور عند التمرير — `Reveal` / `Stagger`
مكوّن عميل واحد (`src/components/motion/Reveal.tsx`) يستعمل **مراقبا مشتركا واحدا**
لكل الصفحة (لا مراقب لكل عنصر)، ويضيف `data-visible="true"` عند التقاطع.
الأنماط في CSS، فلا إعادة تصيير.

- ظهور: `opacity 0→1` + `translateY(10px→0)` بمدة `--motion-diagram`.
- متتالٍ: `.stagger` مع `--stagger-index`، فرق ≤ `60ms`، وكل العناصر تظهر في ≤ 400ms.
- يُشغَّل مرة واحدة، ثم يُفصل المراقب. لا يتكرر عند الرجوع (§17).

### 4.2 ترسيم المسارات — SVG Draw
تُمرَّر البيانات الهندسية الحقيقية إلى المكوّن، ويُحسب الطول من الأحداثيات
(`--draw-length`)، ثم:

```css
.draw-line { stroke-dasharray: var(--draw-length); stroke-dashoffset: var(--draw-length); }
@keyframes drawLine { to { stroke-dashoffset: 0 } }
```

- تُترسم الفروع بترتيب المصدر: من الكلمة → الوصلة → خط الوجه → الرمز → التسمية (§83).
- **لا تُعاد الحركة عند كل تصيير**: تُشغَّل عند التركيب أو عند إنشاء عنصر جديد فقط (§51).

### 4.3 التحديد والتغذية الراجعة
الاختيار يظهر بأربع إشارات متآخرة زمنيا في ≤ 300ms (§47–48):
لون فئة ثابت → إبراز السطر → بروز رمز القارئ → تحديث اللوحة.
التبديل بـ`--motion-fast`، ولا حركة لأي عنصر غير مرتبط بالتحديد.

العكس (اختيار قارئ ⇒ إبراز خطوطه وخفض البقية) يعتمد `data-state="inactive"`
بـ`opacity .22`، لا بإخفاء (§49، §86–87).

### 4.4 التمرير السردي (الرئيسية)
- شريط تقدّم القراءة رفيع (2px) ومتصل بتمرير الصفحة، بلا رقم ضخم (§64).
- قصة «الحل» تُظهر الخط نفسه متحركا بين المراحل عبر `animation-timeline: view()`
  عند دعمه، وبديله ظهور مرحلي عند عدم الدعم.
- لا `ScrollTrigger` في النماذج أو البطاقات أو شريط المحرر (§80).

### 4.5 الانتقال بين الصفحات
منخفض الكثافة (§75، §140): `opacity` + `translateY(4px)` بمدة `--motion-normal`.
الشعور المطلوب: **التطبيق نفسه، مساحة عمل مختلفة** — لا مشهد سينمائي.

### 4.6 الحالات
| الحالة | الحركة |
|---|---|
| تحميل | خط قصير يتشكل ذهابا وإيابا (`.loading-trace`)، لا دوّارة، ولا تحجب الشاشة (§92، §198–199) |
| فراغ | ثابت: نص واضح + رسم من هوية التشجير، بلا إيموجي (§91) |
| خطأ | ثابت: السبب + الإجراء، بلا رسوم طفولية (§93) |
| تنبيه عابر | ظهور `translateY(4px)` في `--motion-fast`، وبقاء ≤ 3s، بلا اهتزاز (§94) |

## 5. تقليل الحركة (§145، §208)

`prefers-reduced-motion: reduce` يُلغي: ترسيم الـ Hero، الـ parallax، التتاليات،
التنقل السلس، النبضات. ويُبقي: التعتيم الفوري، وكل المعلومة، وكل وظيفة.

القاعدة: **لا تُفقد معلومة عند إسقاط الحركة.** كل ما تحمله الحركة من معنى
(ترتيب، علاقة، أولوية) يجب أن يكون موجودا في الحالة الساكنة.

## 6. الأداء (§120–125)

- تُحرَّك `transform` و`opacity` و`stroke-dashoffset` فقط. لا `width/height/top/left`.
- حركة `hover` تُنفَّذ في CSS داخل SVG، بلا `useState` وبلا تحديث مخزن (§122–123).
- عند التحديد: يتغيّر العنصر المرتبط وما يتصل به فقط، لا الشجرة كلها (§124).
- الرسم مذكَّر (`useMemo`) ومقسّم طبقات: نصوص، خطوط، تسميات، تفاعل.
- لا إعادة ترسيم كامل عند كل حركة مؤشر.
- الحالة المستقرة هي الأصل: تجربة الـ Hero **تنتهي**، ولا تبقى مستهلكة للمعالج (§17).

## 7. مخالفات شائعة

- `transition-all` على عنصر كبير.
- تحريك `r` أو `d` أو إحداثيات كلمة.
- `scale` على طبقة الرسم العلمي لتحقيق تأثير تكبير (§159–160).
- تشغيل حركة الدخول عند كل تغيير حالة في المحرر.
- خطوط متوهجة أو نبضات مستمرة.
- حركة على النص القرآني أثناء القراءة (§78).
