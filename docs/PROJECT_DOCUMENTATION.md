# التوثيق الشامل لمشروع التشجير

## 1. نظرة عامة على المشروع

### 1.1 الهدف
بناء منصة احترافية لتشجير القراءات العشر من طريق الطيبة والنشر، مع محرر بصري ذكي يفهم النص القرآني والحركات والأحكام التجويدية.

### 1.2 المميزات الرئيسية
- محرر بصري لرسم خطوط التشجير
- فهم الحركات والأحكام التجويدية
- نظام الأدلة من الطيبة والنشر
- نظام مراجعة العلماء المجازين
- نظام تسجيل القراء والإجازات

## 4. منطق التشجير

### 4.1 مفهوم التشجير
التشجير هو طريقة لتمثيل الاختلافات بين القراءات العشر بشكل بصري، حيث يتم:
1. عرض نص المصحف (رواية حفص عن عاصم) كخط أساسي
2. رسم خطوط أفقية لكل قارئ/راوي
3. ربط الكلمات المتفقة بخطوط
4. إظهار الاختلافات في مكانها الصحيح

### 4.2 قواعد رسم الخطوط
- **قاعدة الترتيب**: من الأعلى للأسفل حسب ترتيب الطيبة
- **قاعدة الوقف**: بعد قالون يقرأ الذي يحتوي على اختلاف من بعده من آخر الآية إلى أولها
- **قاعدة ربط الكلمات**: الكلمات المتفقة تُربط بخط واحد

### 4.3 أنواع الخطوط
| النوع | اللون | الاستخدام |
|-------|-------|-----------|
| أصول | أخضر | الأصول المشتركة |
| فرش | أزرق | الفرش الخاصة |
| مدود | برتقالي | اختلافات المدود |

## 9. كيفية التشغيل

```bash
# تثبيت الحزم
npm install

# تشغيل المشروع (لا حاجة لقاعدة بيانات في هذه المرحلة)
npm run dev
```

التخزين محلي في المتصفح حاليا. مخطط Prisma جاهز ويُفعَّل لاحقا:

```bash
npm run db:generate
npm run db:push
npm run db:seed
```

## 9.1 التوثيق التفصيلي

- `docs/EDITOR.md` — المرجع الكامل للمحرر: النموذج والمحركات والمكونات وسير العمل.
- `docs/DATA.md` — مصادر البيانات وحدود الاعتماد عليها.

2. **أداء المحرر**: استخدام Virtualization للآيات الطويلة
3. **مرونة الخطوط**: خوارزمية ذكية لحساب مواقع الخطوط تلقائياً
4. **قابلية التوسع**: تصميم البيانات يدعم إضافة قراءات مستقبلاً
5. **تجربة المستخدم**: واجهة سلسة تشبه برامج التصميم الاحترافية
