# بيانات القراءات العشر - Qira'at Documentation

## ترتيب القراءات في طيبة النشر

هذا الترتيب المعتمد في المشروع حسب منظومة طيبة النشر في القراءات العشر للإمام ابن الجزري.

---

## القصيدة الطيبة (الأبيات 1-10)

### المقدمة

```
الحمد لله صلّ على محمد     آله وصحبه الأكارم الأزهر
```

### باب الاستعاذة والبسملة

```
1   وَقِفْ يَقُولُ أَعُوذُ بِاللَّهِ مِنَ الرَّجْ     مِ لَمْ يَصِلْ وَاقْطَعِ اسْتَعِذْ وَاسْتَنْفِرُ
```

## ملاحظات هامة

1. **ابن شنبوذ** مشترك في كثير من الطرق
2. الترتيب مهم جداً في التشجير لأنه يحدد أولوية العرض
3. عند إضافة قراءة جديدة يجب تحديد ترتيبها في الطيبة
4. يمكن إضافة طرق أخرى لاحقاً حسب الحاجة
