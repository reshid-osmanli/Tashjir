## 1. مكونات المحرر

كلها في `src/components/editor/`.

### 1.1 TashjeerCanvas

لوحة الرسم الرئيسية. ترسم نص الآية وخطوط التشجير في SVG، وتستقبل تفاعل المستخدم.

```typescript
interface TashjeerCanvasProps {
  fontSize?: number;   // حجم خط المصحف، افتراضي 34
  readOnly?: boolean;  // وضع العرض فقط: يعطّل كل التفاعل التحريري
}
```

**المصدر:** تقرأ الحالة من `useEditorStore` والحسابات من `useAyahTashjeer`. لا تتلقى المستند عبر props، لأن اللوحة والأدوات واللوحات الجانبية تعمل كلها على نفس المستند.

**التفاعل:**

| الحدث | السلوك |
|-------|--------|
| نقر على كلمة (أداة التعليم) | يعلّم الكلمة أو يلغي تعليمها |
| نقر على كلمة (أداة التحديد) | يحددها ويبرز أول اختلاف يشملها |
| نقر على خط | يحدده ويبرز اختلافه |
| نقر على خط (أداة المسح) | يخفي الخط |
| `Ctrl` + عجلة الفأرة | تكبير وتصغير |
| سحب مساحة فارغة أو الزر الأوسط | تحريك اللوحة |

**العناصر الداخلية:** `WordShape` (كلمة بنقاط ارتباطها) · `BranchShape` (خط ببطاقته) · `BranchLabel` · `BaselineBands` (فصل منطقة الأصول عن الفرش) · `Rulers` · `CanvasLegend`.

**لماذا SVG؟** النص العربي يُرسم بخط المصحف بتشكيله دون معالجة يدوية، وكل عنصر قابل للتحديد والاختبار والتصدير، والتكبير متجهي.

### 1.2 EditorToolbar

شريط الأدوات، مقسّم إلى مجموعات: الأدوات · التاريخ · العرض · الرسم · الفئات · اللوحات والحفظ.

```typescript
interface EditorToolbarProps {
  fontSize: number;
  onFontSizeChange: (size: number) => void;
  onExport: () => void;
  onImport: () => void;
  onShowShortcuts: () => void;
}
```

كل زر يحمل اختصار لوحة المفاتيح في `title`. زر الحفظ يتغيّر لونه (كهرماني/أخضر) حسب وجود تعديلات غير محفوظة.

---

### 1.3 AyahNavigator

التنقل في المصحف كاملا.

```typescript
interface AyahNavigatorProps {
  ayahKey: number;
  onNavigate: (ayahKey: number) => void;
}
```

**المميزات:**
- اختيار السورة (114) والآية.
- السابق والتالي مع **العبور بين السور تلقائيا**.
- بحث نصي في المصحف كله بلا تشكيل، **مؤجَّل 220ms** حتى لا يُبحث في 6236 آية عند كل ضغطة مفتاح.
- نقطة `●` بجانب أرقام الآيات التي لها عمل محفوظ.

### 1.4 VariantsPanel

لوحة الاختلافات: مكان العمل العلمي الفعلي.

**بلا props** — تقرأ كل شيء من المخزن.

**قسم الإنشاء:** يعرض الكلمات المعلّمة بخط المصحف، ويتيح اختيار الفئة، ثم زر "إنشاء الاختلاف" الذي يبني اختلافا بوجه أساس جاهز للتحرير.

**قائمة الاختلافات:** مرتبة من آخر الآية إلى أولها (القاعدة المعتمدة). كل صف يعرض الفئة والحالة والعنوان وعدد الأوجه المرسومة، ويتوسع عند التحديد ليعرض الأوجه بنصوصها ونطاقاتها.

يصدّر أيضا مكوّن `StatusBadge` المستخدم في لوحة الخصائص.

### 1.5 VariantEditor

نافذة تحرير كاملة لاختلاف واحد.

```typescript
interface VariantEditorProps {
  variant: Variant;
  onClose: () => void;
}
```

**الأقسام:** بيانات الاختلاف (عنوان، فئة، حالة، مرجع، شرح) · قائمة الأوجه · محرر الوجه المحدد.

**محرر الوجه** يضم: نص الوجه · وصفه · علامة "وجه المصحف" · **محدد النطاق** · ملاحظات · قائمة الأدلة.

#### ScopePicker — أهم عنصر في المحرر

يعرض القراء العشرة، وتحت كل واحد راوييه. النقر على اسم الإمام يختار رواته كلهم أو يلغيهم. لون كل إمام ثابت، فرواة الإمام الواحد يشتركون في اللون.

بعد كل تغيير يُستدعى `normalizeScope` تلقائيا، فلا يُخزَّن "حفص + شعبة" بل "عاصم". يعرض أسفله الوصف المختصر وعدد الرواة من 20.

#### EvidenceList

قائمة الأدلة: المصدر (طيبة/نشر/جنة/آخر) · المرجع · نص الدليل. تعرض تنبيها صريحا حين لا يوجد دليل: «الوجه بلا دليل يبقى مسودة ولا يصح اعتماده».

### 1.6 PropertiesPanel

لوحة القراءة والتفتيش. **بلا props.**

**الأقسام:** حالة المستند · إحصاءات الآية · الكلمة المحددة · الاختلاف المحدد · الخط المحدد وأدلته · **تصفية الرواة**.

تصفية الرواة هي أقوى أداة تدقيق: باختيار راو واحد تظهر خطوطه وحدها، فيتحقق المدقق من قراءته كاملة في الآية دفعة واحدة.

## 2. الخطافات (Hooks)

### 2.1 useAyahTashjeer

`src/hooks/useAyahTashjeer.ts`

يجمع كل ما تحتاجه اللوحة في مكان واحد:

```typescript
useAyahTashjeer(document, filter, options) => {
  ayah;      // بيانات الآية
  words;     // الكلمات
  layout;    // التخطيط (صناديق الكلمات)
  branches;  // الخطوط بعد التصفية والحساب الهندسي
  stats;     // الإحصاءات
  options;   // إعدادات التخطيط المستعملة
  viewBox;   // حدود اللوحة
}
```

كل الحسابات داخل `useMemo` بمفاتيح دقيقة، فلا يُعاد الحساب إلا عند تغيّر المستند أو التصفية فعلا. مهم لأن الآيات الطويلة قد تبلغ مئة كلمة وعشرات الخطوط.

### 2.2 useKeyboardShortcuts

`src/hooks/useKeyboardShortcuts.ts`

```typescript
useKeyboardShortcuts(enabled?: boolean): void
```

يربط 14 اختصارا بإجراءات المخزن. **يتجاهل الاختصارات إذا كان المستخدم يكتب في حقل إدخال**، حتى لا يحذف زر `E` خطا بينما هو يكتب وصف وجه.

يصدّر `SHORTCUT_HINTS` لعرضها في نافذة المساعدة.

## 4. معايير الكود

### التعليقات

- ترويسة عربية في أعلى كل ملف: اسم المكوّن ودوره.
- تُشرح **العلة** لا الوصف: لماذا SVG؟ لماذا التأجيل 220ms؟ لماذا لا تُسجَّل لقطة عند التكبير؟
- القواعد المنهجية تُوثَّق في مكانها من الكود، لا في ملف منفصل فقط.

### الأنماط

- Tailwind CSS 4 عبر `@import 'tailwindcss'`.
- صنف `.input` موحّد لكل حقول الإدخال في `globals.css` — يمنع تكرار عشرات الأصناف في JSX.
- خصائص منطقية للاتجاه: `ms-auto` و`border-s` و`end-1` بدل اليمين واليسار الصريحين.

### الحالة

- المكونات لا تتلقى المستند عبر props، بل تقرأه من `useEditorStore`. السبب: اللوحة والأدوات واللوحات الجانبية تعمل كلها على مستند واحد، وتمريره طبقة بعد طبقة يخلق مصادر تزامن متعددة.
- المكوّنات العرضية الصغيرة (`Row`, `Stat`, `Field`) محلية في ملفاتها، لا تُستخرج قبل أن تُستعمل في ثلاثة مواضع.

### إضافة مكوّن جديد

1. أنشئه في `src/components/{الفئة}/`.
2. ترويسة عربية تشرح الدور.
3. واجهة `Props` موثّقة بالتعليقات.
4. `'use client'` إن كان تفاعليا.
5. وثّقه هنا.
