# تدقيق التنفيذ الحالي — Project Audit

**تاريخ التدقيق:** 2026-10-08  
**النطاق:** شجرة الكود والوثائق كما تعمل في فرع `arena/f510a3db-tashjir`، مقارنةً بخط الأساس `bd5b4e85618f148351caa946100fa3024364c7d0`.

## ما ينفذه المشروع فعليًا

| المجال | التنفيذ المرصود في HEAD |
|---|---|
| المحرر `/editor` | تحرير مستندات التشجير وعرضها في React؛ مستندات العمل تحفظ محليًا عبر واجهة `document-store` و`localStorage`. |
| استوديو المحرك `/studio` | واجهة إعداد واختبار سياسات المحرك؛ الإعدادات والتاريخ لهما stores محلية، وقرارات المحرك تُدار في `src/lib/tashjeer`. |
| المصحف `/quran` | نص ثابت من بيانات المصحف، مع مستندات محفوظة أو تشجير مشتق من القواعد؛ روابط للتحرير والتصدير. |
| التتبع `/tracking` | تجميع قراءة فقط لسجل المستندات والتصحيحات المحلية وآثار resolver، مع روابط عودة للمحرر. |
| القراءات والنقل | بيانات القراءات الأساسية ثابتة؛ `/api/transmissions` يعلن `source: static` ويقرأ بذور `src/data/qiraat-data`. |
| الجلسة/الدخول | دخول محلي في المتصفح، وليس مصادقة خادمية أو حدًا أمنيًا. |
| قاعدة البيانات | ملفات Prisma schema/client/seed موجودة، لكن التطبيق لا يستورد Prisma في صفحات/مكونات/stores، ونقاط النقل الحالية لا تستعلم من PostgreSQL. لا تُعامل المخططات بوصفها backend مستخدمًا الآن. |

## التوثيق القديم والتعارضات

- كانت مقدمات `docs/DATABASE.md` و`docs/ARCHITECTURE.md` تصف PostgreSQL/Prisma كمسار تشغيل حالي، مع مسارات/تكاملات غير موجودة في `src/app`. أضيف تنبيه حالة إلى الوثيقتين يحفظ تفاصيل التصميم ويشير إلى `PROJECT_MAP.md` كمصدر التنفيذ الجاري.
- كانت `docs/PROJECT_DOCUMENTATION.md` تعرض بعض المخططات والميزات بصيغة مكتملة دون بيان أنها مواصفات تاريخية؛ أضيف تنبيه يربطها بسجل الميزات الحالي.
- أوضح `docs/API.md` أصلًا أن التخزين محلي وبيانات النقل ثابتة؛ لم يُعد كتابته.
- عُدّل وصف تصدير الأولويات في `docs/ENGINE_STUDIO.md`: تعديل الأولوية يكون سطرًا واحدًا عند غياب التصادم، أما التصادم فيزيح سلسلة القواعد المعنية ويظهر سطرًا لكل قاعدة أُزيحت.
- لم تُحذف وثائق تصميمية، ولم يُعَد كتابة README؛ أضيفت إحالات حالة بدل إسقاط محتواها التاريخي.

## حدود التدقيق

اختبار runtime للصفحات كان فحص HTTP/SSR عبر خادم التطوير؛ لم يتوفر متصفح headless صالح لتشغيل Playwright أو التقاط أخطاء console من متصفح. لم تُغيّر قواعد المحرك أو حالة البيانات أو business logic، ولم تُعالج مشاكل الخط الأساس الخارجة عن نطاق Registry.
