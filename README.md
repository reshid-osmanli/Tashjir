# مشروع التشجير - نظام القراءات العشر

منصة لتشجير القراءات العشر من طريق الطيبة والنشر، مع محرر بصري يفهم النص القرآني ويرسم خطوط التشجير تلقائيا من الاختلافات المسجّلة.

---

## الفكرة في سطرين

المستخدم **لا يرسم خطوطا**. المستخدم **يسجّل اختلافا قرائيا**: موضعه، وأوجهه، ومن يقرأ بكل وجه، ودليله. ثم يتولى محرك التشجير رسم الخطوط وترتيبها وتوزيعها على المسارات وفق قواعد منهجية ثابتة.

---

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:3000/editor>.

لا حاجة إلى قاعدة بيانات ولا إلى أي إعداد. التخزين محلي في المتصفح في هذه المرحلة.

### أوامر أخرى

```bash
npm run build       # بناء الإنتاج
npm test            # 108 اختبارا
npm run typecheck   # فحص الأنواع
npm run data:quran  # إعادة توليد بيانات المصحف
```

## ما المنجز

### ✅ بيانات المصحف كاملة

114 سورة، 6236 آية، 77,429 كلمة بالرسم العثماني. معرّفات الكلمات حتمية (`سورة×1000000 + آية×1000 + ترتيب`)، فأي خط محفوظ يبقى مرتبطا بكلمته مهما أُعيد التحميل.

### ✅ محرك التشجير

| المحرك | الملف | الدور |
|--------|-------|-------|
| التخطيط | `lib/tashjeer/layout-engine.ts` | قياس الكلمات وتوزيعها RTL مع الالتفاف |
| التشجير | `lib/tashjeer/branch-engine.ts` | توليد الخطوط وترتيبها وتعبئة المسارات |
| النطاقات | `lib/tashjeer/scope.ts` | حل مجموعات القرّاء واختصارها |

**القواعد المنهجية المطبّقة:**

1. وجه المصحف (حفص) لا يُرسم له خط — هو النص المكتوب أصلا.
2. الأصول والمدود فوق النص، والفرش والهمز والوقف تحته.
3. الترتيب من آخر الآية إلى أولها: الخط الأقرب لنهاية الآية يأخذ مسارا أقرب للنص.
4. الخطوط المتباعدة أفقيا تتشارك المسار الواحد (تقليل ارتفاع اللوحة).

### ✅ نظام النطاقات

الحكم الذي يقرأ به 19 راويا يُخزَّن **مرة واحدة**:

```ts
{ kind: 'ALL_EXCEPT', narratorIds: ['narrator-hafs'] }
```

والنظام يختصر أي اختيار تلقائيا: حفص + شعبة تصير "عاصم بكماله".

### ✅ المحرر

- لوحة SVG بتكبير وسحب وشبكة ومساطر.
- تعليم الكلمات بالنقر ← إنشاء اختلاف.
- محرر أوجه كامل: النص، الوصف، النطاق بالنقر على الأئمة والرواة، والأدلة.
- تصفية بالفئة أو **براو واحد** — أقوى أداة تدقيق: تظهر قراءة راو بعينه وحدها.
- تراجع وإعادة على المستند (لا على حالة الواجهة).
- 14 اختصار لوحة مفاتيح.
- تصدير واستيراد JSON.

## ⚠️ تنبيه منهجي

الاختلافات المرفقة مع المشروع (8 مواضع) **مسجّلة بحالة «مسودة» وهي للتشغيل والاختبار فقط**.

لا يجوز الاعتماد عليها علميا قبل مراجعة مختص مجاز ومقابلتها على *النشر* و*طيبة النشر*. نصوص الأدلة إشارات إلى مواضع البحث، لا اقتباس حرفي.

إدخال المادة العلمية وتحقيقها عمل بشري بحت.
