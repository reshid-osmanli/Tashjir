# مشروع التشجير - نظام القراءات العشر

## نظرة عامة

منصة احترافية لتشجير القراءات العشر من طريق الطيبة والنشر، مع محرر بصري ذكي يفهم النص القرآني والحركات والأحكام التجويدية.

## الترتيب المعتمد للقراء حسب طيبة النشر

### القراءات العشر (ترتيب الطيبة)

| # | القارئ | الروايتان |
|---|--------|-----------|
| 1 | نافع المدني | قالون - ورش |
| 2 | ابن كثير المكي | البزي - قنبل |
| 3 | أبو عمرو البصري | الدوري - السوسي |
| 4 | ابن عامر الشامي | هشام - ابن ذكوان |
| 5 | عاصم الكوفي | حفص - شعبة |
| 6 | حمزة الكوفي | خلف - خلاد |
| 7 | الكسائي الكوفي | الليث - الدوري (أبو عمرو) |
| 8 | أبو جعفر المدني | ابن وردان - ابن جماز |
| 9 | يعقوب البصري | رويس - روح |
| 10 | خلف البصري | إدريس - إسحاق |

### ترتيب التشجير (من الأعلى للأسفل)

في المحرر، يتم ترتيب القراء كالتالي:
1. **الأصول**: تُعرض في الأعلى وتشمل كل المصحف
2. **الفرش**: تُعرض حسب ترتيب القارئ من نهاية الآية
3. **المدود**: تُعرض بين الأصول والفرش عند الحاجة

### قاعدة الوقف والابتداء

> بعد قالون يقرأ الذي يحتوي على اختلاف من بعده من آخر الآية إلى أولها

## هيكل المشروع

```
tashjeer/
├── docs/                    # التوثيق
│   ├── ARCHITECTURE.md      # هيكل النظام
│   ├── COMPONENTS.md        # توثيق المكونات
│   ├── DATABASE.md          # توثيق قاعدة البيانات
│   ├── QIRAAT.md            # بيانات القراءات
│   ├── TASHJEER_LOGIC.md    # منطق التشجير
│   └── API.md               # توثيق API
├── src/
│   ├── app/                 # Next.js App Router
│   ├── components/          # المكونات
│   ├── lib/                 # المكتبات والمنطق
│   ├── hooks/               # React Hooks
│   ├── types/               # TypeScript Types
│   └── data/                # البيانات الثابتة
├── prisma/                  # مخطط قاعدة البيانات
└── public/                  # الملفات العامة
```
